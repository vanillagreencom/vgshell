# Clock

Clock shows the date and time on the bar. Click it to open the calendar.

![The clock in the center of the bar](../../../docs/images/plugins/vgs.clock-bar.webp)

## Features

- Click a day to open it in your web calendar.
- Use Manage widgets to add or remove the clock. Drag it on the bar to move it.

## Setup

| Setting | What it changes |
| --- | --- |
| Clock format | How the clock shows the date and time. |
| Calendar | The web calendar that opens for a day. Choose Google Calendar, Outlook or your own address with `{year}`, `{month}` and `{day}`. |
| Open with | The browser or browser profile that opens your web calendar. |
