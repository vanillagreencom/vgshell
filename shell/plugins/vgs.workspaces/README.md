# Workspaces

Workspaces shows your Hyprland workspace numbers on the bar. Click a number to go to that workspace.

![The bar with the workspace numbers on its left](../../../docs/images/plugins/vgs.workspaces-bar.webp)

## Features

- One number for each workspace, in order. The workspace you are on is highlighted.
- A click on a number goes to that workspace.
- With more than one display, each bar can show only the workspaces on its own display.
- It can also show the workspaces in your Hyprland workspace rules that have no windows.
- Add it to the bar, move it or take it off in Manage widgets, as any other bar item.

## Setup

| Setting | What it changes |
| --- | --- |
| Split by display | Each display's bar shows only the workspaces on that display, and highlights the one that display shows. |
| Show empty workspaces | Adds the workspaces in your Hyprland workspace rules that have no windows. With Split by display on, a rule with no display shows on no bar. |
