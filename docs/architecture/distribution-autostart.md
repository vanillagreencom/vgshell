# Autostart

Covers: packaging/install-system.sh, packaging/install-tree-system.manifest, scripts/check-install-tree.sh, scripts/test-install-tree.sh, bin/lib/post-install.txt

This file holds the XDG autostart entry a system package ships. The install tree and the first-install text are [distribution.md](distribution.md)'s.

- A system package starts the shell with an XDG autostart entry, `$SYSCONFDIR/xdg/autostart/vgs.desktop`, which `packaging/install-system.sh` writes: `Type=Application`, `Name=VGS`, a `Comment`, `Exec=$PREFIX/bin/vgsh run`, `OnlyShowIn=Hyprland;` and `NoDisplay=true`. The installer is the one place its text lives.
- `Exec` names the command by its absolute path. `systemd-xdg-autostart-generator` resolves `Exec` when it runs and makes no unit for an entry whose command it cannot find, so the absolute path keeps the entry independent of the user manager's `PATH`. `package-rule` refuses a prefix `Exec` would have to quote before the entry is written.
- A Hyprland session that uwsm manages starts `xdg-desktop-autostart.target`. The generator turns the entry into `app-vgs@autostart.service`, wanted by that target, whose `ExecCondition` runs `systemd-xdg-autostart-condition "Hyprland" ""`, so the unit starts only where `XDG_CURRENT_DESKTOP` names Hyprland. A plain Hyprland session reads no XDG autostart entry; for it the first-install text gives the `hyprland.lua` line ([distribution.md § First-install text](distribution.md#first-install-text)).
- An owner who has both gets one shell: `vgsh run` holds the instance lock, and the second run exits 75 ([runtime.md § Process](runtime.md#process)).
- A user turns the entry off with an entry of the same name under `~/.config/autostart` that holds `Hidden=true`, as the XDG autostart specification states. The install script and the flake set no `SYSCONFDIR` and install no entry.
## Invariants

1. A system install's entry makes the host generator's `app-vgs@autostart.service`, wanted by `xdg-desktop-autostart.target`, whose `ExecStart` runs the installed `vgsh run` and whose `ExecCondition` limits it to Hyprland; the entry is mode 0644. Enforced by `scripts/test-install-tree.sh`, which installs at a scratch `PREFIX` and `SYSCONFDIR` with no `DESTDIR`, so the command the entry names exists, and runs the host's generator with `XDG_CONFIG_DIRS` on the scratch `xdg` directory and an empty `XDG_CONFIG_HOME`. The installer and the generator run with a scratch `HOME` and `XDG_CONFIG_HOME`, and the row reads that neither wrote there. Its controls are an installer whose entry has no `OnlyShowIn`, one whose entry is `Hidden`, one that installs the entry mode 0600, which `scripts/check-install-tree.sh` reports, and one that writes a user entry under `XDG_CONFIG_HOME`. A host without the generator exits 77 with `reason=autostart-generator-missing`; `scripts/test-jarvis-setup.py` runs that closing verdict with a control copy that exits 0 without the branch.
