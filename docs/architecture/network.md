# Network

Covers: shell/plugins/vgs.network/**, scripts/test-network-logic.js, scripts/smoke/rows/network.sh, scripts/smoke/fixtures/devices/network.py, scripts/test-network-share.py, scripts/smoke/fixtures/devices/network-qr-tools.py


The `vgs.network` service owns scanning and publishes network state. Its bar widget, flyout and System pane read one status record. The flyout and pane compose one local body from `qs.Ui` components and theme tokens. [D098](../decisions/D098-networkmanager-only-secrets.md) defines the backend and secret store.

## Ownership

- `Networking.devices` and each device's network model are Quickshell's NetworkManager objects. The service snapshots only public connection facts. Device and network objects never enter status.
- Every open body acquires a lease with its own QML instance identity. Close and destruction release that lease. The service alone writes `WifiDevice.scannerEnabled`. It keeps scanning while any lease exists, turns the scanner off after the last close, and moves it when the Wi-Fi device changes.
- The service owns one pending operation, identified by its network object and key. It reconciles only that operation. A radio cancellation or source loss releases it. Successful changes release it through native state or profile signals. A request with no transition has a ten-second watchdog; an observed transition has a two-minute bound. A terminal failed connect keeps its owner for one second so a following credentials-failure signal can create the correct prompt. Expiry shows a retry message. Background or unrelated failures cannot clear an operation or replace a password prompt. The service observes each network's `connectionFailed` signal. It first calls `connect()`. A credentials failure on a saved PSK network creates a prompt instead of retrying the same saved profile. A new PSK network's `NoSecrets` failure creates the same prompt.
- The masked field captures and clears its password before the synchronous preparatory IPC action can publish a prompt change. It also clears on cancel, close, device loss and prompt replacement. It sends the PSK directly to `WifiNetwork.connectWithPsk`. The preparatory IPC action carries only the network identity. The PSK reaches no VGS IPC call, process argument, status record, configuration or log.
- `systemctl show` reads NetworkManager's installation and service state at start and on open. The `nmcli general permissions` probe reads network-control permission without authentication. `no` and `auth` refuse changes. Failed or incomplete probes stay unavailable. The views show when the permission check is unavailable and leave native controls available. No probe switches, starts or installs a network service.
- Connection details come from `nmcli -t device show`, one service-owned process. The parser preserves escaped colons and backslashes. Its allowlist excludes secrets. A Details menu action shows the allowlisted result in the flyout as well as the pane. The pane's missing-tool action uses its plugin-scoped `status.act`.
- Automatic joining is the Quickshell device's `autoconnect` switch. NetworkManager owns that setting. VGS stores no copy in its configuration.

## Runtime facts

The [Quickshell Networking reference](https://quickshell.org/docs/v0.3.1/types/Quickshell.Networking/Networking/) defines the read models. The [WifiNetwork reference](https://quickshell.org/docs/v0.3.1/types/Quickshell.Networking/WifiNetwork/) recommends `connect()` before `connectWithPsk` and limits PSKs to WPA, WPA2 and SAE. Signal strength is a share from zero to one. The [WifiDevice reference](https://quickshell.org/docs/v0.3.1/types/Quickshell.Networking/WifiDevice/) defines `scannerEnabled`. [runtime-devices.md](runtime-devices.md) records the singleton's first-read limit: a service that starts after that first read needs a shell restart before Quickshell sees it.

Quickshell's backend identity is constant. It cannot distinguish an absent NetworkManager installation from a stopped service. The service reads the documented [systemctl show interface](https://www.freedesktop.org/software/systemd/man/latest/systemctl.html#show%20%5BPATTERN%E2%80%A6%7CJOB%E2%80%A6%5D) for that distinction. Permissions and details use the documented [nmcli interface](https://www.networkmanager.dev/docs/api/latest/nmcli.html). Quickshell alone changes the radio, connection and password.

## Evidence

Saved-network sharing creates a view owner only after an explicit Share. Its helper uses public profile metadata to select the matching saved Wi-Fi profile. Only that profile's password is read. It escapes the Wi-Fi QR delimiters and feeds the payload to `qrencode` through stdin. No password enters argv, VGS IPC, status, logs, configuration or files. The view holds only the encoded matrix. Close clears the state and destroys the helper, collector and renderer, including late buffered output. The renderer uses whole modules from `Theme.qrMatrix`. Open, OWE, WEP, WPA, WPA2 and SAE saved profiles can be shared; enterprise profiles cannot. NetworkManager remains the persistent secret owner.

The required commands are declared by Network. Their temporary required core rows provide the current Nix PATH and curl installation path until VGS-769 supplies manifest-owned packaging. Arch and Fedora require the same packages. The existing requirement notice handles a missing command; sharing adds no second installer.

`scripts/test-network-share.py` uses private command doubles to check saved disconnected profiles, hidden networks, delimiters, supported security types, refusal and cancellation. Production controls put a secret into argv or a file and omit escaping. Each must fail its independent guard. The nested row checks Share from the keyboard, whole modules, owner destruction and close before buffered output finishes. Its owner-retention control must expose the retained view. These fixtures use no host network, bus or authentication.

`scripts/test-network-logic.js` tests strength conversion, ordering, security labels, saved-password reprompt, service states, permission refusal and details escaping. Its mutations must turn the suite red. `scripts/smoke/rows/network.sh` reads every kind over S08's private NetworkManager mock. It reads lease lifetime, device replacement, the real credentials-failure signal, a keyboard join and forget, radio control, absent and stopped states and the absence of the joined PSK from status, configuration and logs. The mock accepts only the exact nonempty synthetic password and writes no received secret to disk. Refused connect, password update, disconnect and forget operations each release the owner and permit a retry. The row also checks terminal failure, radio cancellation, source loss, ignored background failures, visible flyout details, and failed or missing optional permission probes. Its copied plugin sends an empty PSK as a control, suppresses the reprompt, leaves scanning on after close, and consumes Enter without activation as controls. The scanner reader reads the actual Wi-Fi device after the final lease closes. It also keeps the replaced fake device long enough to prove its scanner stopped. The fixture never contacts the host bus or a real network device.
