# Yaru icon themes

The `Yaru-*` directories here are colour variants of the Yaru icon theme, from Ubuntu's `yaru-theme-icon` 26.10.3 package, built from https://github.com/ubuntu/yaru.

- Change: each `index.theme` that inherited the base theme `Yaru` inherits `Adwaita` instead, because VGS does not ship the base theme. No icon file is changed.
